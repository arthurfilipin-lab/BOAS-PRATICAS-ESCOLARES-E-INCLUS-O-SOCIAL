# BOAS-PRATICAS-ESCOLARES-E-INCLUS-O-SOCIAL
Boas Práticas Escolares e Inclusão Social é um site educativo que promove a inclusão, o respeito à diversidade, a acessibilidade e a convivência escolar. Reúne conteúdos fundamentados em diretrizes educacionais reconhecidas, com o objetivo de incentivar práticas que contribuam para uma educação mais justa, acolhedora e acessível para todos.
